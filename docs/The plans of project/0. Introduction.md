# 0. Introduction: WebGIS Giám sát Mưa Gió Bão tích hợp AI Agent cảnh báo

> **Định hướng:** WebGIS hiển thị dữ liệu mưa/gió/bão thời gian thực, tích hợp AI Agent chủ động cảnh báo và hỏi-đáp bằng ngôn ngữ tự nhiên.

---

## 1. Scope of Work

### 1.1. Mục tiêu dự án

Xây dựng một hệ thống WebGIS cho phép người dùng theo dõi tình hình mưa, gió và bão trên bản đồ theo thời gian thực. Hệ thống tích hợp AI Agent có hai chức năng:

- **Chủ động:** Liên tục giám sát dữ liệu, tự phát hiện khi các chỉ số vượt ngưỡng nguy hiểm (mưa lớn, gió mạnh, bão tiến gần) và tự sinh cảnh báo kèm giải thích bằng ngôn ngữ tự nhiên.
- **Bị động:** Cho phép người dùng đặt câu hỏi tự nhiên (ví dụ: _"khu vực nào đang mưa to nhất?"_, _"cảnh báo vừa rồi vì sao?"_) và nhận câu trả lời dựa trên dữ liệu thực tế trong hệ thống.

### 1.2. In-scope

- Bản đồ WebGIS hiển thị dữ liệu mưa và gió theo thời gian thực.
- Hiển thị các cơn bão đang hoạt động trên bản đồ.
- Bộ ngưỡng cảnh báo.
- AI Agent chủ động: Giám sát định kỳ, phát hiện khi dữ liệu vượt ngưỡng và tự sinh cảnh báo (kèm giải thích bằng ngôn ngữ tự nhiên).
- AI Agent bị động: Trả lời câu hỏi tự nhiên của người dùng dựa trên dữ liệu trong hệ thống, bao gồm cả việc giải thích thêm về một cảnh báo đã phát ra.
- Giao diện chat + khu vực hiển thị cảnh báo tích hợp trên web.

### 1.3. Out-of-scope

- Tự xây mô hình machine learning dự đoán quỹ đạo bão.
- Cảnh báo real-time qua SMS/push notification.
- Ứng dụng di động riêng biệt (chỉ web, responsive ở mức cơ bản).
- Dữ liệu bão có độ chính xác cấp độ nghiệp vụ khí tượng.

---

## 2. Công nghệ áp dụng

| Thành phần            | Công nghệ                                             |
| :-------------------- | :---------------------------------------------------- |
| **Dữ liệu thời tiết** | OpenWeatherMap API                                    |
| **Dữ liệu bão**       | GDACS (Global Disaster Alert and Coordination System) |
| **Database**          | PostgreSQL + PostGIS                                  |
| **Backend**           | Java - Spring Boot                                    |
| **AI Agent**          | Gemini API                                            |
| **Frontend**          | React + Leaflet                                       |
