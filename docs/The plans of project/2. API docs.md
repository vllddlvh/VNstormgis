## 1. Chuẩn Thiết Kế & Quy Ước Chung (API Standards)

### 1.1. Base URL & Phiên Bản (Versioning)
- **Môi trường phát triển cục bộ (Local Development):** `http://localhost:8080/api/v1`
- **Môi trường sản xuất (Production):** `https://api.weathergis.vn/api/v1`

Tất cả các endpoint đều có tiền tố phiên bản `/api/v1`.

### 1.2. Định Dạng Trao Đổi & Quy Chuẩn Không Gian (GeoJSON)
- **Data Interchange:** Định dạng mặc định JSON UTF-8 (`Content-Type: application/json; charset=utf-8`).
- **GeoJSON Standard:** Các dữ liệu có thuộc tính không gian địa lý (trạm quan trắc, vị trí tâm bão, quỹ đạo bão, vùng ảnh hưởng cảnh báo) tuân thủ tiêu chuẩn mở **RFC 7946 GeoJSON** sử dụng hệ quy chiếu trắc địa chuẩn thế giới **WGS84 (EPSG:4326)** với thứ tự tọa độ mảng `[Kinh độ (Longitude), Vĩ độ (Latitude)]`. Định dạng này sẵn sàng để nạp trực tiếp vào thư viện **Leaflet** thông qua hàm `L.geoJSON(data)`.

### 1.3. Mô Hình Phân Quyền & Kiểm Soát Truy Cập (Access Control Matrix)
Theo đặc tả SRS (Mục 18 - Access Control Matrix và Mục 14.10 - Privacy & Compliance):
- 🟢 **ROLE-PUBLIC (Khách vãng lai / Người dùng công cộng):**
  - Truy cập ẩn danh, không yêu cầu đăng ký/đăng nhập tài khoản cá nhân (tuân thủ nguyên tắc `NFR-PRV-001` không thu thập dữ liệu PII).
  - Được phép xem bản đồ số, tra cứu số liệu thời tiết, vị trí bão active, danh sách cảnh báo, và gửi câu hỏi hỏi đáp với AI Chatbot (bị giới hạn tần suất bởi Rate Limiter theo phiên/IP).
  - Phiên chat được quản lý thông qua mã phiên ẩn danh (`session_token`).
- 🟡 **ROLE-ADMIN (Quản trị viên hệ thống):**
  - Quản lý cấu hình bộ tham số ngưỡng cảnh báo rủi ro (SR-ALT-001, UC-003).
  - Kích hoạt quét ngưỡng thủ công hoặc tra cứu nhật ký đồng bộ dữ liệu (`data_sync_logs`).
  - Yêu cầu Header xác thực quản trị:
    ```http
    Authorization: Bearer <admin_access_token>
    ```
    hoặc mã bí mật quản trị viên:
    ```http
    X-Admin-Api-Key: <admin_api_key>
    ```
- 🔴 **ROLE-WORKER (Tiến trình tự động chạy ngầm nội bộ):**
  - Dành riêng cho Cron Worker nội bộ để kích hoạt đồng bộ dữ liệu OpenWeatherMap, GDACS, và tiến trình so khớp ngưỡng tự động (SR-ING-002, SR-ALT-002).
  - Yêu cầu Header bảo mật bắt buộc:
    ```http
    X-Internal-Secret: <system_cron_secret_key>
    ```

> [!IMPORTANT]
> **Phạm vi Ngoài Lề (Out-of-Scope Enforcement):** Hệ thống không triển khai cơ chế đăng ký người dùng nhận tin cảnh báo qua SMS, Email hay Mobile Push Notification (theo `BR-RULE-005` / `SYS-RULE-005`). Toàn bộ cảnh báo chỉ hiển thị trực quan trên giao diện Web.

### 1.4. Cấu Trúc Đóng Gói Phản Hồi Chuẩn (Standard Response Envelope)

#### Phản hồi thành công thông thường (Standard Success Response):
```json
{
  "success": true,
  "data": { ... },
  "message": "Mô tả kết quả thực thi (nếu cần)"
}
```

#### Phản hồi phân trang (Paginated Success Response):
```json
{
  "success": true,
  "data": [ ... ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 63,
    "total_pages": 4
  }
}
```

#### Phản hồi GeoJSON chuẩn cho Leaflet:
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [108.2022, 16.0544]
      },
      "properties": { ... }
    }
  ]
}
```

#### Phản hồi lỗi chuẩn (Error Response Envelope):
```json
{
  "success": false,
  "error": {
    "code": "VAL_ALT_INVALID_PARAM",
    "message": "Thông điệp lỗi chi tiết cho client",
    "details": [
      {
        "field": "threshold_numeric_value",
        "issue": "Giá trị ngưỡng phải là số thực dương lớn hơn 0"
      }
    ]
  }
}
```

### 1.5. Bảng Mã Trạng Thái HTTP Chuẩn
| HTTP Status | Ý Nghĩa Kỹ Thuật | Kịch Bản Áp Dụng Trong Hệ Thống |
| :--- | :--- | :--- |
| `200 OK` | Thành công | Yêu cầu truy vấn hoặc cập nhật dữ liệu được xử lý trọn vẹn |
| `201 Created` | Đã tạo mới thành công | Tạo mới cấu hình ngưỡng cảnh báo, tạo phiên chat, tạo tin nhắn thành công |
| `400 Bad Request` | Lỗi tham số / Validation | Dữ liệu đầu vào vi phạm quy tắc kiểm tra (VAL-xxx), câu hỏi chat rỗng, v.v. |
| `401 Unauthorized` | Thiếu chứng thực | Gọi endpoint quản trị mà không truyền Admin Token / API Key |
| `403 Forbidden` | Từ chối truy cập | Sai hoặc thiếu header `X-Internal-Secret` hoặc không có quyền quản trị |
| `404 Not Found` | Không tìm thấy tài nguyên | Không tồn tại mã trạm, mã cơn bão, mã cảnh báo hoặc mã ngưỡng yêu cầu |
| `429 Too Many Requests` | Vượt hạn mức gọi API | Gửi câu hỏi chat quá tần suất quy định (Rate Limit) để bảo vệ token Gemini |
| `500 Internal Server Error` | Lỗi hệ thống nội bộ | Lỗi kết nối cơ sở dữ liệu PostgreSQL/PostGIS, lỗi logic backend không dự đoán |
| `503 Service Unavailable` | Dịch vụ ngoài gián đoạn | Dịch vụ Google Gemini API, OpenWeatherMap hoặc GDACS bị timeout/mất kết nối |

### 3.1. Phân Hệ Điểm Trạm Quan Trắc (`/locations`)

#### 1. Lấy danh sách điểm quan trắc / tỉnh thành
- **Endpoint:** `GET /api/v1/locations`
- **Quyền hạn:** 🟢 Public
- **Truy vết SRS:** SR-MAP-001, UC-001, BR-MAP-03
- **Mô tả:** Trả về danh sách các điểm trạm quan trắc khí tượng trên cả nước. Hỗ trợ định dạng GeoJSON chuẩn để hiển thị trực tiếp lên bản đồ Leaflet.

### 3.3. Phân Hệ Theo Dõi Bão & Quỹ Đạo GDACS (`/storms`)

#### 1. Lấy danh sách các cơn bão
- **Endpoint:** `GET /api/v1/storms`
- **Quyền hạn:** 🟢 Public
- **Truy vết SRS:** SR-STM-001, SR-STM-002, SR-STM-003, SYS-RULE-001
- **Mô tả:** Mặc định hệ thống **chỉ trả về các cơn bão đang hoạt động** (`status = 'active'`) theo đúng quy tắc loại trừ bão đã tan khỏi chế độ giám sát khẩn cấp (`SYS-RULE-001`).
- **Query Parameters:**
  - `status` *(string, optional, default: `active`)*: Giá trị cho phép: `active`, `dissipated`, `all`.

## 4. Ma Trận Quy Tắc Kiểm Tra Hợp Lệ Dữ Liệu (Validation Rules)

Toàn bộ các quy tắc kiểm tra hợp lệ được đồng bộ tuyệt đối từ **SRS Mục 12 (Validation Requirements)**:

| Validation ID | Trường Dữ Liệu / Đối Tượng | Loại Kiểm Tra | Điều Kiện Hợp Lệ | Mã Lỗi HTTP | Phản Hồi Khi Vi Phạm |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **VAL-LOC-001** | `geom` (Tọa độ trạm) | Range & Format | Kinh độ $\in [-180.0, 180.0]$, Vĩ độ $\in [-90.0, 90.0]$ | `400 Bad Request` | `VAL_LOC_INVALID_COORDINATES`: Tọa độ không gian nằm ngoài phạm vi WGS84 |
| **VAL-WTH-001** | `rain_1h`, `rain_3h` | Number Range | Số thực $\ge 0.0$ ($mm$) | `400 Bad Request` | `VAL_WTH_NEGATIVE_RAIN`: Lượng mưa không được mang giá trị âm |
| **VAL-WTH-002** | `wind_speed`, `wind_gust` | Number Range | Số thực $\ge 0.0$ ($m/s$) | `400 Bad Request` | `VAL_WTH_NEGATIVE_WIND`: Vận tốc gió không được mang giá trị âm |
| **VAL-WTH-003** | `wind_direction` | Degree Range | Số thực $\in [0.0, 360.0]$ độ | `400 Bad Request` | `VAL_WTH_INVALID_DEGREE`: Hướng gió phải nằm trong khoảng góc 0 đến 360 độ |
| **VAL-STM-001** | `status` (Cơn bão) | Enum Allowed | Thuộc tập `['active', 'dissipated']` | `400 Bad Request` | `VAL_STM_INVALID_STATUS`: Trạng thái bão không hợp lệ |
| **VAL-ALT-001** | `parameter` (Bộ ngưỡng) | Enum Allowed | Thuộc tập `['rain_1h', 'rain_3h', 'wind_speed', 'wind_gust', 'storm_distance_km']` | `400 Bad Request` | `VAL_ALT_INVALID_PARAM`: Tham số đo đạc không được hỗ trợ |
| **VAL-ALT-002** | `operator` (Toán tử) | Enum Allowed | Thuộc tập `['>=', '>', '<=', '<', '=']` | `400 Bad Request` | `VAL_ALT_INVALID_OPERATOR`: Toán tử điều kiện không hợp lệ |
| **VAL-ALT-003** | `threshold_value` | Number Range | Số thực dương $> 0.0$ | `400 Bad Request` | `VAL_ALT_NEGATIVE_VALUE`: Giá trị ngưỡng kích hoạt phải là số thực dương lớn hơn 0 |
| **VAL-CHT-001** | `message` (Khung chat) | Length & Format | Chuỗi UTF-8 có độ dài từ 1 đến 500 ký tự sau khi cắt tỉa khoảng trắng | `400 Bad Request` | `INVALID_PROMPT`: Câu hỏi không được để trống hoặc vượt quá 500 ký tự |
| **VAL-SEC-001** | `X-Internal-Secret` | Matching | Chuỗi ký tự khớp chính xác 100% với biến môi trường hệ thống | `403 Forbidden` | `AUTH_FORBIDDEN_INTERNAL`: Mã bí mật nội bộ không chính xác hoặc bị thiếu |

## 5. Bảng Mã Lỗi Hệ Thống & Kịch Bản Ngoại Lệ (Error Handling Matrix)

Được đồng bộ từ **SRS Mục 13 (Error Handling Requirements)**:

| Error ID | Error Code | HTTP Status | Điều Kiện Gây Lỗi | Xử Lý Phía Backend | Phản Hồi Trả Về Cho Client / Người Dùng |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **ERR-EXT-001** | `OWM_SYNC_FAILED` | `503 Service Unavailable` | OpenWeatherMap API bị timeout hoặc trả về lỗi 5xx | Ghi nhật ký lỗi, duy trì bản ghi thời tiết gần nhất | `"Dữ liệu đang được đồng bộ lại từ chu kỳ trước"` |
| **ERR-EXT-002** | `OWM_RATE_LIMIT` | `429 Too Many Requests` | OpenWeatherMap trả về HTTP 429 | Áp dụng Exponential Backoff, gửi cảnh báo cho DevOps | Tiếp tục phục vụ dữ liệu đã lưu trong PostGIS cache |
| **ERR-EXT-003** | `GDACS_UNAVAILABLE` | `503 Service Unavailable` | GDACS API không phản hồi hoặc trả về dữ liệu hỏng | Giữ nguyên danh mục bão active hiện thời, ghi log lỗi | Bản đồ hiển thị trạng thái bão của chu kỳ trước đó |
| **ERR-AI-001** | `AI_GENERATION_FALLBACK` | `200 OK` (Internal Fallback) | Gemini API timeout hoặc lỗi 503 khi sinh cảnh báo chủ động | Tự động kích hoạt Deterministic Fallback Template điền số liệu | Cảnh báo vẫn xuất bản bình thường, không trễ giờ |
| **ERR-AI-002** | `AI_SERVICE_UNAVAILABLE` | `503 Service Unavailable` | Gemini API lỗi hoặc timeout khi người dùng chat | Bắt ngoại lệ, không để sập tiến trình, ghi log | `"Hệ thống trợ lý AI đang tạm thời gián đoạn kết nối. Vui lòng thử lại sau ít phút."` |
| **ERR-AI-003** | `AI_HALLUCINATION_DETECTED` | `200 OK` (Auto corrected) | Gemini sinh văn bản sai lệch số liệu so với DB | Đối soát phát hiện vi phạm, thay bằng bản mẫu chuẩn | Bản tin cảnh báo được sửa về số liệu chuẩn xác |
| **ERR-USR-001** | `RATE_LIMIT_EXCEEDED` | `429 Too Many Requests` | Người dùng gửi câu hỏi chat quá tần suất cho phép | Chặn ở tầng Gateway/Middleware, không gọi Gemini | `"Bạn đang gửi câu hỏi quá nhanh. Xin vui lòng chờ [X] giây."` |
| **ERR-SEC-001** | `AUTH_FORBIDDEN_INTERNAL` | `403 Forbidden` | Gọi API nội bộ nhưng thiếu/sai `X-Internal-Secret` | Ghi nhật ký bảo mật Audit Log kèm IP nguồn; ngắt luồng | `"Yêu cầu bị từ chối: Khóa xác thực nội bộ không hợp lệ"` |
| **ERR-DB-001** | `DATABASE_CONNECTION_LOST` | `500 Internal Error` | PostgreSQL/PostGIS bị gián đoạn kết nối | Backend kích hoạt reconnection pool, ghi log Fatal | `"Hệ thống đang bảo trì hoặc gặp sự cố kết nối máy chủ dữ liệu"` |

```jsx
  switch (severity) {
    case 'CRITICAL': return '#991b1b'; // Đỏ đậm
    case 'DANGER':   return '#dc2626'; // Đỏ tươi
```

### 6.2. Vẽ Lớp Bão Đang Hoạt Động & Quỹ Đạo Di Chuyển (SRS SR-STM-002)

```jsx
import React, { useEffect, useState } from 'react';
import { GeoJSON } from 'react-leaflet';
import L from 'leaflet';

export const ActiveStormTrackLayer = ({ stormId }) => {
  const [trackData, setTrackData] = useState(null);

  useEffect(() => {
    if (!stormId) return;
    // Gọi endpoint lấy quỹ đạo bão
    fetch(`/api/v1/storms/${stormId}/track`)
      .then((res) => res.json())
      .then((data) => setTrackData(data))
      .catch((err) => console.error('Lỗi tải quỹ đạo bão:', err));
  }, [stormId]);

  if (!trackData) return null;

  return (
    <GeoJSON
      data={trackData}
      style={(feature) => {
        if (feature.geometry.type === 'LineString') {
          return {
            color: '#dc2626',
            weight: 3,
            dashArray: '6, 6',
            opacity: 0.85,
          };
        }
      }}
      pointToLayer={(feature, latlng) => {
        const { is_current, category } = feature.properties;
        return L.circleMarker(latlng, {
          radius: is_current ? 12 : 6,
          fillColor: is_current ? '#b91c1c' : '#f87171',
```

### 6.3. Tích Hợp Khung Chat AI Grounding & Tương Tác Cảnh Báo (SRS 17.3, UC-005, UC-006)

```jsx
import React, { useState } from 'react';

export const AIChatDrawer = ({ selectedAlertId }) => {
  const [messages, setMessages] = useState([]);
  const [inputPrompt, setInputPrompt] = useState('');
  const [loading, setLoading] = useState(false);
  const [sessionToken] = useState(() => localStorage.getItem('chat_token') || 'sess_' + Math.random().toString(36).substr(2));

  const handleSendMessage = async () => {
    if (!inputPrompt.trim() || loading) return;

    const userMsg = { sender_type: 'user', content: inputPrompt };
    setMessages((prev) => [...prev, userMsg]);
    setInputPrompt('');
    setLoading(true);

    try {
      const res = await fetch('/api/v1/chat/message', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          session_token: sessionToken,
          message: userMsg.content,
          referenced_alert_id: selectedAlertId || null,
        }),
      });

      const result = await res.json();
      if (result.success) {
        setMessages((prev) => [
          ...prev,
          { sender_type: 'assistant', content: result.data.reply }
        ]);
      } else {
        setMessages((prev) => [
          ...prev,
          { sender_type: 'assistant', content: `Lỗi: ${result.error.message}` }
        ]);
      }
    } catch (err) {
      setMessages((prev) => [
        ...prev,
        { sender_type: 'assistant', content: 'Không thể kết nối tới máy chủ. Xin vui lòng thử lại.' }
      ]);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="ai-chat-container" style={{ padding: '16px', display: 'flex', flexDirection: 'column', height: '100%' }}>
      <div className="chat-history" style={{ flex: 1, overflowY: 'auto', marginBottom: '12px' }}>
        {messages.map((m, idx) => (
          <div key={idx} style={{ textAlign: m.sender_type === 'user' ? 'right' : 'left', margin: '8px 0' }}>
            <span style={{
              display: 'inline-block',
              padding: '8px 12px',
              borderRadius: '8px',
              background: m.sender_type === 'user' ? '#2563eb' : '#f1f5f9',
              color: m.sender_type === 'user' ? '#ffffff' : '#0f172a',
              maxWidth: '80%'
            }}>
              {m.content}
            </span>
          </div>
        ))}
        {loading && <div style={{ color: '#64748b', fontStyle: 'italic' }}>AI đang phân tích dữ liệu trắc địa...</div>}
      </div>

      <div style={{ display: 'flex', gap: '8px' }}>
        <input
          type="text"
          value={inputPrompt}
          onChange={(e) => setInputPrompt(e.target.value)}
          onKeyDown={(e) => e.key === 'Enter' && handleSendMessage()}
          placeholder="Hỏi AI về mưa, gió, bão hoặc cảnh báo..."
          style={{ flex: 1, padding: '8px 12px', borderRadius: '6px', border: '1px solid #cbd5e1' }}
        />
        <button onClick={handleSendMessage} disabled={loading} style={{ padding: '8px 16px', background: '#2563eb', color: '#fff', border: 'none', borderRadius: '6px' }}>
          Gửi
        </button>
      </div>
    </div>
  );
};
```

## 7. Tổng Kết & Ma Trận Kiểm Tra Tính Toàn Vẹn (API Quality & Traceability)

Tài liệu Đặc tả RESTful API này đáp ứng 100% các tiêu chí chất lượng kỹ thuật:

2. **Chuẩn Hóa Mô Hình Thực Thể Dữ Liệu:** Khóa chính của trạm đo và cảnh báo sử dụng chuẩn UUID v4, mã bão sử dụng chuẩn GDACS ID, các trường dữ liệu thời tiết khớp từng ký tự với bảng `weather_records` trong [1. ERD.md](file:///Users/dllv/Documents/GitHub/WebGIS-for-weather-of-Vietnam/docs/The%20plans%20of%20project/1.%20ERD.md).

4. **Chuẩn Hóa Quy Chuẩn Không Gian:** 100% endpoint phục vụ bản đồ đều hỗ trợ chuẩn RFC 7946 GeoJSON hệ quy chiếu WGS84 (EPSG:4326), tích hợp tự nhiên vào thư viện Leaflet.
